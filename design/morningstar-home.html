MORNINGSTAR

Static mockup of LauncherActivity at 360×800 dp — the same dimensions, tokens, bundled fonts and arc math as the Kotlin. Nothing here is a screenshot; there is no Android SDK in this workspace.

Honest status

Implemented in the working tree, never compiled by AGP, never run on a device. MORNINGSTAR.md says the same. The geometry is host-verified; the pixels are a proposal.

What the code actually draws

  • True-black OLED canvas with three crimson compass rings, one gilded, a vignette and drifting dust (seeded embers, so the drift is identical every launch).
  • Sigil clock — a 24-tick compass whose three arcs are battery / memory / load off one 270° ring starting at 135°, with a gilded triangle turning once every three minutes. Permission-free, polls only while visible.
  • Shard command bar — 45° chamfers everywhere, crimson caret, four target chips, rotating hint.
  • Output pane — 96 dp collapsed ↔ 250 dp open, colour-coded by line prefix.
  • Drawer as typography — index numeral, name, a 30 dp empty gutter, no icons. Favourites get an ember bloom and a crimson needle.
  • Sovereign dock — five glass circles, CORE in gilded, then λ SPEAK.

What to look at

  • The command bar is crowded. Four target chips plus the caret leave ~120 dp for the input; a long hint clips mid-word. The code sets maxLines = 1, so it degrades the way you see — but a shorter hint or icon-only chips would read better.
  • Density of the drawer. At 39 dp per row only ~8 of ~12 apps fit above the dock without scrolling.
  • Contrast. Ash/Smoke on true black is beautiful at night and thin in sunlight — the 8 sp overlines are the first thing to disappear.
  • Eight font textures. Cinzel, Inter and JetBrains Mono are all bundled; the emoji in the welcome line falls back to the system font, which is the one place the type discipline breaks.
